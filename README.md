# Oreum Brainwave Report Skill

교육채널 오름 백주경 박사 스타일의 **BQ2 뇌기능 검사지 → 뇌기능 분석결과 보고서** 자동 생성 Hermes 스킬입니다.

## Concept

백주경 박사가 BQ2 뇌기능 검사지 PDF를 Hermes에 제공하면, Hermes가 원자료의 정량 지표를 추출·검증하고 뇌과학·뇌파분석 관점의 해석과 백주경 박사의 교육·상담적 정성 해석을 결합해 `뇌기능 분석결과 보고서` 초안을 생성합니다.

## Included

- `SKILL.md` — Hermes skill workflow
- `references/bq2-metric-schema.md` — BQ2 metric normalization schema
- `references/interpretation-rules.md` — quantitative → qualitative interpretation rules
- `references/tone-and-safety-guide.md` — medical-safety and report tone rules
- `templates/professional-report.md` — professional report template
- `templates/metric-verification-table.md` — source/report numeric verification table

## Safety

This skill is for education/counseling reference reports. It does not produce medical diagnoses. Final review and approval belongs to 백주경 박사.
